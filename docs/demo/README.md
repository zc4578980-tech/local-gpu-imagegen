# Protocol Demo

`preview-loop.gif` is a deterministic, model-free illustration of the control protocol. It shows a brief, exact route confirmation, a bounded first round, structured rejection with a preserve/change contract, and a candidate that still waits for the user's decision.

It is not generated by an image model and is not evidence of model quality, GPU performance, client-host compatibility, or completed public acceptance. The machine-readable boundary and GIF digest are retained in `demo-manifest.json`.

Regenerate it with Python 3.11 or later and no third-party dependencies:

```shell
python scripts/build_demo.py
```
